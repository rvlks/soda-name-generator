# SODA — Name Generator

A big, bold, near-full-screen name generator for a soda fountain concept, in the
spirit of a stripped-back editorial (SSENSE-ish) layout — with rising bubbles and
a fizz burst on every reveal.

Tap anywhere (or **Space**) to cycle through base words, connectors, and anchors:
`SODA PARLOUR`, `FIZZ & CO.`, `FLOAT CO.`, `SODA & SUNDRIES`, `FOUNTAIN COMPANY`…

- **Space** — generate
- **S** — save the current name
- **C** — copy the current name
- Saved names persist in your browser (localStorage).

Just open `index.html` — no build step.
